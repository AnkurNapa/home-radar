# Home Radar

A one-page shortlist of 3 BHK homes to rent in central Bengaluru. It has a map, a rent summary by area, a budget range slider, rush hour drive times and the walk to the nearest metro.

Open `index.html` or the GitHub Pages link. Everything lives inside the one file, including the base map, so it also works offline.

Asking rents come from NoBroker, Square Yards and RealEstateIndia. Drive and walk times come from Google Maps. The base map is from OpenStreetMap.
