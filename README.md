# Home Radar

A one-page shortlist of 3 BHK homes to rent in Whitefield, Bengaluru, ranked by the walk to the nearest Purple Line metro station. It has a map with every station, a rent summary by station, a budget slider, a walk filter and the number of stops to Cubbon Park.

Open `index.html` or the GitHub Pages link. Everything lives inside the one file, including the base map, so it also works offline.

Asking rents come from NoBroker. Station positions, addresses, walking routes and the base map all come from OpenStreetMap.
